# 🚀 StartupMentor AI

StartupMentor AI is an AI-powered web application developed using Streamlit that analyzes startup ideas and evaluates startup logos.

## Features
- AI Startup Analyzer
- Logo Analyzer
- SWOT Analysis
- Market Score Visualization
- Branding Suggestions

## Technologies Used
- Python
- Streamlit
- Google Colab
- NVIDIA Tesla T4 GPU
- Matplotlib
- Pillow
- Hugging Face Transformers
